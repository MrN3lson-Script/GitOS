# GitOS
**Building a truly open operating system, one Pull Request at a time.**

Welcome to GitOS. This isn't just another Linux fork — it's a completely custom operating system built from the ground up by the open-source community. 

Our core architecture currently focuses on:
* **Custom Bootloader:** Written in pure NASM (x86 Assembly).
* **Modular Kernel:** Developed in C++ for maximum control and performance.
* **Minimalist UI:** A strict, lightweight console-based interface.

### Community-First Development
GitOS belongs to its contributors. We believe the best low-level code is written collaboratively. Whether you are an Assembly wizard, a C++ kernel developer, or a QA tester running QEMU environments, your code is welcome here.

**How to contribute:** Fork the repository -> Write your epic code -> Submit a Pull Request.
